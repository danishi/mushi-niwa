# むしにわ 「おきゃくさん」の虫リサーチ（5種）

調査日: 2026-11-08
目的: 庭にしばらく現れる「おきゃくさん」の虫（飼育しない）をタップしたときに出す短い豆知識と、3D モデルの大きさ・色を、出典で裏付ける。

凡例:
- ⚠️ = 信頼できる資料で裏付けできなかった項目、または資料によって記述が違う項目。ゲーム内では断定しない書き方にするか、使わない。
- ✅ = 下書きのままで問題ない。✏️ = 言い回しを直したほうがよい（直した文を併記）。
- 子ども向けの文は、ひらがな中心で、漢字は `{漢字|かんじ}` 記法で書く。
- 出典の略号: 【世界大百科】=平凡社『改訂新版 世界大百科事典』、【ニッポニカ】=小学館『日本大百科全書』、【図鑑NEO】=小学館の図鑑NEO[新版]昆虫、【ブリタニカ】=ブリタニカ国際大百科事典 小項目事典、【マイペディア】=平凡社『百科事典マイペディア』、【大辞泉】=小学館『デジタル大辞泉』、【日国】=小学館『精選版 日本国語大辞典』（いずれもコトバンク掲載分）。【環境省トンボ】=環境省資料「3－2 主要な調査対象トンボ種の概要」（PDF）。【Honda】=Honda「生きもの図鑑」。【名古屋市】【島根県】【目黒区】=各自治体のページ（URLは各節の出典）。【ja.wiki】=日本語版Wikipedia（補助的に使う）。
- 5種のうち、オカダンゴムシは**昆虫ではない**（甲殻類）。ずかん・豆知識で「こんちゅう」と書かないこと。

## 1. シオカラトンボ

### 基本
- 和名: シオカラトンボ（雌の俗称: ムギワラトンボ）
- 学名: *Orthetrum albistylum speciosum*（Uhler, 1858）。ヨーロッパ〜中央アジアに原名亜種がいて、日本産は亜種 *speciosum* とされる【環境省トンボ】【Honda】。
- 分類: 昆虫綱 トンボ目 トンボ科【世界大百科】ほか
- 大きさ:
  - 体長 50〜55mm【世界大百科】【図鑑NEO】【Honda】。48mm 内外【ブリタニカ】、50mm 内外【マイペディア】。
  - 全長 47〜61mm（♂♀とも）【環境省トンボ】。
  - 後ろばねの長さ 約43mm【Honda】。
- 分布: 北海道〜南西諸島。日本の平地でいちばん普通のトンボ【世界大百科】【ニッポニカ】【環境省トンボ】。
- 季節: 成虫は4〜10月【ブリタニカ】【図鑑NEO】【Honda】（東京付近で4月末〜9月末【世界大百科】、5月上旬〜10月下旬【環境省トンボ】）。

### 確認できた事実
- **オスの体色の変化**: オスは成熟すると体が黒くなり、白い粉（白粉）をふく【世界大百科】【ニッポニカ】【ブリタニカ】【図鑑NEO】【マイペディア】。白粉は胸から腹の前のほう（腹の6節目まで）につく【Honda】【環境省トンボ】。老熟したオスは白粉で「鉛白色」になる【マイペディア】。
  - 名前の「しおから」は、この白い粉を塩に見立てたものとされる【ja.wiki】。
- **オスの目**: 複眼は深い水色【環境省トンボ】。
- **メスと若いオス**: 黄褐色の地に黒い斑紋がある【ブリタニカ】【Honda】。メスと未熟なオスは鮮やかな黄色で、腹の背に黒いすじが2本ある【マイペディア】。腹は麦わら模様、複眼は緑色【環境省トンボ】。
  - 雌を体色からムギワラトンボと呼ぶ【世界大百科】【ニッポニカ】【ブリタニカ】。未熟なオスも麦わら色なので、同じように呼ばれることがある【ニッポニカ】【マイペディア】【Honda】。
  - 年をとったメスにも薄く白粉をおびる個体があり、オスのように全身に白粉をふく個体もいる【環境省トンボ】。
- **ヤゴ（幼虫）**: 平地の浅い水たまり、池、沼、湿地、水田などの水中で育つ【世界大百科】【ニッポニカ】【図鑑NEO】。水底の泥にもぐり、ミジンコや小さな水生昆虫を食べる【Honda】。脚が短く、体に剛毛がある【世界大百科】【ニッポニカ】。幼虫期間は2〜3か月【Honda】（2〜8か月【環境省トンボ】）。ヤゴで冬を越す【Honda】【環境省トンボ】。

### 下書き文の検証
1. 「オスは おとなに なると、しおを ふいたような みずいろに なるよ。メスは むぎわらいろで「ムギワラトンボ」とも よばれるよ」
   - ✏️ 前半を直す。資料が書いているのは「黒くなって白い粉をふく」「灰白色」「鉛白色」で、体が「みずいろ」になるという記述はない。みずいろなのは**目**【環境省トンボ】。
   - 後半（ムギワラトンボ）は ✅。
   - 修正案: 「オスは おとなに なると、しおを ふいたように しろっぽく なるよ。メスは むぎわらいろで「ムギワラトンボ」とも よばれるよ」
   - 目の色も入れる場合: 「オスは おとなに なると、からだに しおを ふいたような しろい こなが つくよ。めは みずいろだよ」
2. 「{幼虫|ようちゅう}の ヤゴは みずの なかで くらすよ」
   - ✅ そのまま使える。少し足すなら「{幼虫|ようちゅう}の ヤゴは、いけや たんぼの みずの なかで くらすよ」。

### 3D モデル用（成熟したオス）
- 大きさ: 体長 50〜55mm、後ろばね 約43mm。
- 胸〜腹の6節目: 白っぽい灰色〜青みがかった灰色の粉（つやの少ない粉っぽい質感）。下地は黒【Honda】【環境省トンボ】。
- 腹の7節目から先: 黒。白粉が6節目までなので、先端の数節が黒く残る【環境省トンボ】。腹の先の尾毛（びもう）は白【環境省トンボ】（学名 *albistylum* は「白い尾」の意）。
- 複眼: 深い水色【環境省トンボ】【ja.wiki】。
- はね: 透明【ブリタニカ】。ほぼ無紋で、縁紋（はねの先の小さな四角）は黒【環境省トンボ】。
- 参考（メス・若いオス）: 黄褐色〜黄色の地に黒いすじ、複眼は緑色、はねの先に小さな褐色斑【マイペディア】【環境省トンボ】。

## 2. モンシロチョウ

### 基本
- 和名: モンシロチョウ（紋白蝶）
- 学名: *Pieris rapae*（Linnaeus, 1758）【ja.wiki】。日本産は亜種 *P. r. crucivora* とされることがある。*Artogeia rapae* の表記もある（コトバンクの見出し）。
- 分類: 昆虫綱 チョウ目 シロチョウ科
- 大きさ: はねを開いた幅（開張）5〜6cm【大辞泉】【日国】。開張5cm前後で、春型は小さく、オスはメスより小さい【世界大百科】（検索抜粋）。前ばねの長さ 約3cm【ja.wiki】。
- 季節: 成虫は3月ごろ〜10月ごろ【ja.wiki】。島根県の平地では4〜5世代、第1世代の成虫は3月下旬から出る【島根県】。
- 越冬: さなぎで冬を越す【大辞泉】【島根県】。

### 確認できた事実
- **はねの模様**: はねは白く、前ばねの先が黒い。前ばねに黒い紋が2つ、後ろばねの前のふちに黒い紋が1つある【大辞泉】【日国】。前ばねの黒い紋が名前の由来【世界大百科】（検索抜粋）。はねの裏は淡い黄色【日国】。
- **オスとメスの違い**: メスは黒い部分が多く、前ばねのつけ根が灰色。オスは黒い部分が小さい【ja.wiki】。⚠️ 雌雄差を明記した事典・公的資料は今回取得できなかった。
- **季節による違い**: 春の成虫は夏の成虫より白っぽい【ja.wiki】。季節で色や模様が変わる【日国】。
- **幼虫（あおむし）**: 幼虫は緑色で「アオムシ」と呼ばれる【日国】【ja.wiki】。キャベツ、ハクサイ、アブラナ、ダイコンなどを食べる【大辞泉】【日国】。いちばん好むのはキャベツで、ほかにハクサイ、ダイコン、カブ、カリフラワー、ワサビ（いずれもアブラナ科）【島根県】。
  - かえったばかりの幼虫は約2mm、育ちきると約30mm。全身が緑色で、短い毛が密に生えている【島根県】。
  - 卵は約3日、幼虫は約15日、さなぎは約5日（適温のとき）【島根県】。

### 下書き文の検証
1. 「{幼虫|ようちゅう}は キャベツなど アブラナの なかまの はを たべる あおむしだよ」
   - ✅ そのまま使える【大辞泉】【日国】【島根県】。
2. 追加案（任意）: 「まえの はねに くろい もんが ふたつ あるよ。それで「もんしろちょう」って いうんだよ」【大辞泉】【世界大百科】
3. 追加案（任意）: 「さなぎの すがたで ふゆを こすよ」【大辞泉】【島根県】

### 3D モデル用
- 大きさ: 開張 5〜6cm（前ばね 約3cm）。体長は⚠️（標準値の資料なし。小型個体の記録で15〜19mm）。
- はね（表）: 白。前ばねの先（翅頂）が黒〜灰黒色。前ばねの中ほどに黒い丸い紋が2つ。後ろばねの前のふちに黒い紋が1つ【大辞泉】【日国】。
  - メスにするなら黒い部分を濃く・大きく、前ばねのつけ根を灰色に。オスなら黒い部分を小さく【ja.wiki】⚠️。
- はね（裏）: 淡い黄色【日国】。
- 胴体: 黒っぽい灰色で白い毛がある ⚠️（一般的な外見。資料での明記は未取得）。

## 3. トノサマバッタ

### 基本
- 和名: トノサマバッタ
- 学名: *Locusta migratoria*
- 分類: 昆虫綱 バッタ目 バッタ科
- 大きさ:
  - 体長 ♂約35mm、♀約50mm【世界大百科】【ニッポニカ】【ブリタニカ】。
  - ♂35〜40mm、♀45〜65mm【図鑑NEO】。
  - はねの先まで45〜65mm、日本最大のバッタ【マイペディア】。
  - 前ばねは ♂約25mm、♀約45mm【世界大百科】（検索抜粋）。
- すみか: 河原や、地面が見えるような乾いた草地【世界大百科】【ニッポニカ】【図鑑NEO】。
- 季節: 成虫は夏〜秋【世界大百科】【ニッポニカ】【ブリタニカ】。7〜11月【図鑑NEO】、8〜10月【マイペディア】。
- 食べ物: イネ科（とカヤツリグサ科）の葉【世界大百科】【図鑑NEO】【マイペディア】。

### 確認できた事実
- **体の色**: 緑色型と褐色型がある【ブリタニカ】【ニッポニカ】【マイペディア】。色の濃さで緑色型・褐色型・黒褐色型と、その中間型に分けられる【世界大百科】。
  - 色は、群れの密度、まわりの背景、温度、成長段階などで変わり、二択ではなく連続的に変わる（化学と生物 2016）。
  - 群れて暮らすと「群生相」になり、褐色ではねが長く、長い距離を飛ぶ【ニッポニカ】【マイペディア】。ゲームでは群生相（大発生・農業被害）の話は扱わない。
- **うしろあし**: バッタ類の後ろあしは太く長く、よく跳ねる【大辞泉】（バッタ項）。後ろあしの腿節（もも）の内側に黒い斜めの帯が2本、ひざは黒、脛節（すね）は橙色〜橙黄色【世界大百科】【ニッポニカ】【ブリタニカ】。
- **飛ぶ力**: 飛ぶ力が強い【ブリタニカ】【図鑑NEO】。バッタ類の中でもっとも活発に飛ぶ【世界大百科】。
  - ⚠️ 何メートル飛ぶかという数値は、信頼できる資料で確認できなかった。数字は出さない。

### 下書き文の検証
1. 「うしろあしが おおきくて、とおくまで とべるよ。みどりいろの こと ちゃいろの こが いるよ」
   - 色の部分は ✅【ブリタニカ】【ニッポニカ】【世界大百科】。
   - ✏️ 前半を直す。「とべる」が「跳ぶ（ジャンプ）」と「飛ぶ（はねで）」のどちらか分からず、「後ろあしが大きいから遠くまで飛べる」と読める。跳ねるのは後ろあし、遠くまで飛ぶのははねなので、分けて書く。
   - 修正案: 「ふとくて ながい うしろあしで ぴょーんと はねて、はねを ひろげて とおくまで とぶよ。みどりいろの こと ちゃいろの こが いるよ」
   - 短くするなら: 「うしろあしで ぴょーんと はねて、そのまま はねで とんでいくよ。みどりいろの こと ちゃいろの こが いるよ」

### 3D モデル用
- 大きさ: 体長 ♂約35mm、♀約50mm（はねの先まで 45〜65mm）。
- 体色: 緑色型（全身が緑）か褐色型（全体が褐色）の2パターン【ブリタニカ】【ニッポニカ】。
- 前ばね: 褐色に白っぽいまだら模様（褐色型の写真での観察。⚠️ 文章資料での明記は未取得）。
- 後ろあし: 腿節が太く大きい。腿節の内側に黒い斜めの帯2本、ひざは黒、脛節は橙色【世界大百科】【ニッポニカ】。

## 4. オカダンゴムシ

### 基本
- 和名: オカダンゴムシ（ふつう「ダンゴムシ」と呼ばれる種）
- 学名: *Armadillidium vulgare*（Latreille, 1804）
- 分類: **昆虫ではない**。節足動物門 甲殻綱（軟甲綱）等脚目（ワラジムシ目）オカダンゴムシ科。エビやカニと同じ甲殻類【名古屋市】【大辞泉】【日国】。
- 大きさ: 成体の体長 約14mm【名古屋市】【大辞泉】。約1cm、体の幅は体長の約半分【ja.wiki】。最大18mm（英国の等脚類研究グループ BMIG）。
- すみか: 倒木や石の下、落ち葉の中【大辞泉】【日国】。家のまわりに多い【名古屋市】。
- 食べ物: 雑食【名古屋市】。落ち葉や枯れ草など【ja.wiki】。
- 由来: 外来種で、明治以降に日本に入ったと考えられている【名古屋市】。人や動物に害はない【名古屋市】。

### 確認できた事実
- **丸くなる**: 触れると体を丸める【大辞泉】。刺激を受けると球のように丸くなり、この点でワラジムシと区別できる【日国】。ワラジムシは丸くならない【世界大百科】【ブリタニカ】【マイペディア】（ワラジムシ項）。
- **甲殻類**: エビやカニと同じ甲殻類で、等脚目に属する【名古屋市】。
- **あしの数**: 胸に7対の歩くあしがある【ja.wiki】。等脚目は、7つある胸の節それぞれに胸脚（あし）がある【日国】（等脚目項）。等脚目は胸の節ごとに1対のあしをもつ【名古屋市】。→ 成体は **7対＝14本** で、利用者の認識どおり。
  - ⚠️ 等脚類の子（マンカ幼体）は最後の1対がなく、6対＝12本で生まれ、脱皮して7対になるとされる（英語版 Wikipedia「Manca」）。オカダンゴムシで確かめた日本語の公的資料は未取得。ゲームで「うまれたときは12ほん」とは書かないほうが安全。
- **体の色**: オスは黒灰色。メスはいくぶん淡く、黄褐色のものもいる【名古屋市】。灰褐色〜青灰色【大辞泉】。

### 下書き文の検証

## 5. アブラゼミ

### 基本
- 和名: アブラゼミ
- 学名: *Graptopsaltria nigrofuscata*（Motschulsky, 1866）
- 分類: 昆虫綱 カメムシ目（半翅目）セミ科
- 大きさ:
  - はねの先まで 5.6〜6cm【日国】、約5.5cm【大辞泉】、56〜60mm【ja.wiki】。
  - 体長 28〜33mm、はねを入れると60mm弱【Honda】。
- 分布: 北海道〜屋久島。朝鮮半島・中国東北部にもいる【ja.wiki】。
- 季節: 7〜9月、多いのは7月下旬〜8月中旬【目黒区】。7月〜9月上旬に多く、10〜11月に鳴き声を聞くこともある【Honda】。
- 食べ物: 成虫も幼虫も木の汁を吸う。成虫はサクラ・ナシ・リンゴなどバラ科の木を好む【Honda】【日国】。

### 確認できた事実
- **はね**: 褐色で不透明【日国】【目黒区】【ja.wiki】。濃淡のまだらがある【日国】。赤褐色で、油がしみたような紋がある【大辞泉】。羽化したばかりのときは白っぽい【ja.wiki】。
  - 比較: クマゼミのはねは透明【目黒区】。
- **体の色**: 黒〜赤褐色【目黒区】。全体に黒く、背と腹に白い粉がある【日国】。全身につやがある【Honda】。黒褐色〜暗い青色で、前胸の背中に大きな褐色の紋が2つ【ja.wiki】。
- **鳴き声**: 「ジージリジリ」【目黒区】。「ジージー」【日国】。油を熱したときの「ジリジリ」に似ていることが名前の由来といわれる【Honda】。鳴くのはオスだけ【Honda】。
- **幼虫の期間**: 幼虫期間は6〜7年【日国】。7年目に地上に出て羽化する【大辞泉】。
  - ⚠️ 年数は資料によって幅がある。セミ全般で「ふつう6、7年」【日国】（セミ項）、「数年ののち」【大辞泉】（セミ項）、「3〜5年」とする自然観察資料もある。アブラゼミの年数を野外で確かめた学術資料は今回取得できなかった。ゲームでは年数を出さず「なんねんも」にとどめる。

### 下書き文の検証
1. 「はねが ちゃいろで すけていない、めずらしい セミだよ」
   - 「はねが ちゃいろで すけていない」は ✅【日国】【目黒区】。

2. 「{幼虫|ようちゅう}は つちの なかで なんねんも くらすよ」

3. 鳴き声「ジージリジリ」
   - ✅ 目黒区の表記と一致【目黒区】。
   - 追加案（任意）: 「あぶらで あげものを する ときの「ジリジリ」に にた こえだから、アブラゼミって いう そうだよ」【Honda】（由来は「といわれる」なので「〜そうだよ」にする）
